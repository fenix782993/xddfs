# 🔥 FENIX COIN — ULTRA FULL
Telegram Bot + Mini App gaming platform starter.

## Included
- Telegram Bot (aiogram 3)
- Telegram Mini App frontend
- PostgreSQL + asyncpg
- Telegram native Dice/Darts/Football/Basketball/Bowling/Slots
- PvP duel system
- PvE
- Mines 5x5 engine
- Crash engine
- Roulette engine
- Referrals: 600 Fenix Coin per confirmed referral
- Missions and admin-channel mission creation
- Daily bonus / streak
- Leaderboard / profile / XP / levels
- Shop / inventory / clans / tournaments database foundation
- Promo codes / achievements database foundation
- Admin commands
- Render + GitHub Actions
- Original Fenix visual assets

Fenix Coin is an in-app virtual currency in this template. No cash-out or real-money wagering is implemented.

## Run
cp .env.example .env
pip install -r requirements.txt
python -m app.main

## Render
Deploy with render.yaml and set BOT_TOKEN, ADMIN_IDS, ADMIN_CHANNEL_ID, BOT_USERNAME and WEBAPP_URL.
